# Budget Tracker

A simple, responsive web application for tracking daily expenses and managing personal spending.

## Features

- Add expenses with a name, amount, category, and date
- Edit existing expenses
- Delete expenses with confirmation
- Filter expenses by category
- Automatically calculate total spending and expense count
- Save expenses using browser Local Storage
- Responsive design for desktop and mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/mandeepheir/budget_tracker.git
   ```
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## How It Works

The application stores expenses in your browser using `localStorage`. Your saved expenses remain available after refreshing the page in the same browser.
